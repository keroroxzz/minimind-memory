\title{Exact Memory Interfaces:\
Address Factorization and Executor Locality}
\author{Draft theory note}
\date{}

\begin{document}
\maketitle

\begin{abstract}
We study two narrow questions behind the phrase ``separate reasoning from
memory.''  First, when can a component that only performs exact key--value
operations be correct for \emph{every} legal runtime state?  In a one-shot,
key-addressed model, universal zero-error retrieval is equivalent to the
existence of a common injective address factorization of write and query
interfaces.  Second, we characterize exactly what a claimed bounded-read
``reasoning'' module entails: the task answer must be invariant on every
class of states and queries that yields the same declared query view and read
transcript.  We also prove that a faithful, predeclared query witness turns
this semantic execution into physical Store reads, and exhibit a family of
finite two-hop tasks with two adaptive reads but an arbitrarily large
worst-case gap against address-oblivious point reads.  Finally, we prove an
observation-indistinguishability statement for open-world abstention.  These
are representation results relative to a fixed task semantics; they neither
show that natural-language canonicalization can be learned nor show that it
cannot.
\end{abstract}

\section{Motivation (prose)}

A recurring engineering picture is a language model that \emph{reasons} and a
separate runtime store that \emph{remembers}.  Retrieval systems demonstrate
useful external memory empirically, but this does not by itself state when
such a composition is correct.  The narrow issue considered here is upstream
of neural architecture: write and read inputs must refer to the same runtime
location, and distinct live referents must not collide.

The note deliberately treats the language model as a possible implementation
of an interface, not as an axiom in a theorem.  Value formation, latent/KV
delivery, retention policy, and a reasoning executor are separate problems.
The present results therefore establish a necessary-and-sufficient condition
only for a restricted key-addressed retrieval contract.

\section{A minimal key-addressed setting}

\begin{definition}[Task and semantic state]\label{def:task}
Fix finite or countable sets: a referent domain \(\Dom\), write utterances
\(\Wr\), query utterances \(\Qu\), a key space \(\Ky\), and a value space
\(\Va\) with \(\lvert\Va\rvert\geq 2\).  The task supplies partial semantic
maps
\[
  \semw:\Wr\rightharpoonup\Dom\times\Va,
  \qquad
  \semq:\Qu\rightharpoonup\Dom .
\]
Let \(\Wr_0\subseteq\operatorname{dom}\semw\) and
\(\Qu_0\subseteq\operatorname{dom}\semq\) be the scope at issue.  Write
\(\semw(w)=(d,v)\) when \(w\) asserts value \(v\) for referent \(d\), and
write \(\semq(q)=d\) when \(q\) asks for \(d\).

The covered referents are
\[
  \Dom_0=\operatorname{proj}_{\Dom}(\semw(\Wr_0))=\semq(\Qu_0).
\]
We assume \emph{bi-witnessed scope}: every \(d\in\Dom_0\) has at least one
write witness in \(\Wr_0\) and one query witness in \(\Qu_0\).  A semantic
state is a finite partial map \(S:\Dom_0\rightharpoonup\Va\); let
\(\mathcal S\) denote the set of all such states.  The one-point
\emph{lookup answer} is the externally specified function
\[
 \Alkup(S,q)=
 \begin{cases}
   S(\semq(q)), & \semq(q)\in\operatorname{dom}S,\\
   \bt, & \text{otherwise.}
 \end{cases}
\]
\end{definition}

\begin{definition}[One-shot key-addressed execution]\label{def:execution}
An addressing interface is a pair of deterministic typed maps
\[
 C_w:\Wr\to\Ky\cup\{\bt\},\qquad
 C_r:\Qu\to\Ky\cup\{\bt\}.
\]
A runtime store is a partial map \(M:\Ky\rightharpoonup\Va\), with exact
\(\mathrm{get}(M,k)=\bt\) exactly when \(k\notin\operatorname{dom}M\).
For \(k\in\Ky\), \(\mathrm{put}(M,k,v)\) creates a new entry if \(k\) is
absent and otherwise returns \(\mathsf{conflict}\); it never silently
overwrites a distinct value.

A legal history \(H=(w_1,\ldots,w_n)\) consists of utterances in \(\Wr_0\)
whose referents are pairwise distinct.  It induces
\(S_H(d_i)=v_i\) for \(\semw(w_i)=(d_i,v_i)\).  A one-shot execution writes
each \(w_i\) at \(C_w(w_i)\), requiring a new entry, then answers \(q\) by
\(\mathrm{get}(M_H,C_r(q))\) when \(C_r(q)\in\Ky\), and by \(\bt\) otherwise.
There is no channel from the executor to \(M_H\) other than this single
exact \(\mathrm{get}\).  The reachable semantic-state scope of this execution
model is
\[
  \mathcal S_{\Wr_0}=\{S_H : H \text{ is a legal history over }\Wr_0\}
  \subseteq\mathcal S.
\]
\end{definition}

\begin{definition}[Universal exactness]\label{def:ue}
The interface has \emph{universal exactness}, denoted \(\UE\), on
\((\Wr_0,\Qu_0)\) if, for every legal history \(H\), every write is admitted
as a new entry and every \(q\in\Qu_0\) is answered exactly as
\(\Alkup(S_H,q)\).
The quantifier is over all finite legal histories in the stated semantic
scope, not an average-case distribution.  When
\(\mathcal S_{\Wr_0}=\mathcal S\) (for example, if the scope supplies
alternative writes for every value assignment), this is universal correctness
over all finite semantic states.
\end{definition}

\section{What is forced by state variation}

\begin{lemma}[State-independence]\label{lem:state}
Let \(F:\Qu\to\Va\cup\{\bt\}\) be any function that does not depend on the
runtime semantic state \(S\).  If there exist
\(S_0,S_1\in\mathcal S_{\Wr_0}\) and \(q\) such that
\(\Alkup(S_0,q)\neq\Alkup(S_1,q)\), then \(F\) is not exact-correct on
both states.
\end{lemma}

\begin{proof}
The value \(F(q)\) is fixed, whereas exact correctness would require it to
equal two distinct task-supplied answers.
\end{proof}

\begin{remark}
Lemma~\ref{lem:state} says only that exact correctness across varying
reachable states needs \emph{some} runtime-state channel.  It does not prescribe a
key--value store, vector database, guard, neural mechanism, or approximate
notion of correctness.  Its role is load-bearing but elementary.
\end{remark}

\section{What a reasoning--knowledge split can formally mean}

The slogan has content only after the executor's observation interface is
fixed.  Let \(\overline{\Va}=\Va\cup\{\bt\}\), and let
\(S^{\bt}(d)=S(d)\) if \(d\in\operatorname{dom}S\) and \(\bt\) otherwise.

\begin{definition}[Adaptive point-read policy]\label{def:policy}
Fix a query view \(\tau:\Qu_0\to\mathcal T\) and an integer \(r\geq0\).
Write
\[
 \mathcal H_r=\bigcup_{t=0}^{r}(\Dom_0\times\overline{\Va})^t
\]
for the set of possible read transcripts.  An \emph{adaptive \(r\)-read
policy} \(\pi\) maps a query view \(u\in\mathcal T\) and every
prior transcript
\[
 h=((d_1,x_1),\ldots,(d_t,x_t))
 \in(\Dom_0\times\overline{\Va})^t,\qquad t<r,
\]
to either \(\mathsf{halt}\) or a next referent \(d\in\Dom_0\).  An admissible
policy may not repeat a referent already appearing in \(h\).  On state \(S\)
and query view \(u\), the induced transcript
\(\operatorname{tr}_{\pi}(S,u)\) is obtained by recursively reading
\(x_{t+1}=S^{\bt}(d_{t+1})\), where
\(d_{t+1}=\pi(u,h_t)\), until it halts or has made \(r\) reads.

For a state scope \(\mathcal X\subseteq\mathcal S\), an admissible policy
is \emph{address-oblivious on \(\mathcal X\)} if, for every
\(u\in\mathcal T\), there is one finite nonrepeating referent sequence such
that the referent sequence of \(\operatorname{tr}_{\pi}(S,u)\) is a prefix
of it for every \(S\in\mathcal X\).  Such a policy may use retrieved values
to halt early, but not to choose the next referent conditional on continuing.
It is \emph{oblivious on \(\mathcal X\)} if that prefix has the same length
for every \(S\in\mathcal X\).  Thus an oblivious policy makes neither its
next-referent nor its halting decision depend on retrieved values on the
declared state scope.

An executor is \emph{no-bypass relative to \((\tau,\pi)\)} if its output has
the form
\[
 E\bigl(\tau(q),\operatorname{tr}_{\pi}(S,\tau(q))\bigr),
 \qquad E:\mathcal T\times\mathcal H_r\to\mathcal Y,
\]
for a deterministic function \(E\), with no other access to \(S\).  Thus
``no bypass'' is an explicit information-flow restriction, not merely an
architectural description.  Because \(\pi\) receives only \(\tau(q)\), its
address trace cannot convey additional information about \(q\) to \(E\).
\end{definition}

\begin{theorem}[Adaptive executor-locality criterion]\label{thm:locality}
Fix \(\tau\), an adaptive \(r\)-read policy \(\pi\), a state scope
\(\mathcal X\subseteq\mathcal S\), and a task answer
\(A:\mathcal X\times\Qu_0\to\mathcal Y\).  There exists a deterministic
executor that is exact on \(\mathcal X\) and no-bypass relative to
\((\tau,\pi)\) if and only if for every \(S,S'\in\mathcal X\) and
\(q,q'\in\Qu_0\),
\[
 \bigl(\tau(q),\operatorname{tr}_{\pi}(S,\tau(q))\bigr)
 =\bigl(\tau(q'),\operatorname{tr}_{\pi}(S',\tau(q'))\bigr)
 \quad\Longrightarrow\quad A(S,q)=A(S',q'). \tag{L}
\]
\end{theorem}

\begin{proof}
If an executor exact on \(\mathcal X\) exists, equal pairs on the left give
it equal inputs and hence equal outputs, which exactness identifies with the
two task answers.  Conversely, under (L), define \(E(t,h)\) to be \(A(S,q)\)
for any pair with \(S\in\mathcal X\) and
\((\tau(q),\operatorname{tr}_{\pi}(S,\tau(q)))=(t,h)\), and assign
an arbitrary output to pairs that never occur.  Condition (L) makes this
definition well defined, and the resulting executor is exact by construction.
\end{proof}

\begin{remark}[A necessary query-side condition]
If condition (L) holds, then for every fixed \(S\in\mathcal X\),
\[
 \tau(q)=\tau(q')\quad\Longrightarrow\quad A(S,q)=A(S,q').
\]
Indeed, equal query views induce equal transcripts by induction on the
deterministic policy.  Equivalently, for each state \(S\), the map
\(A(S,\cdot)\) factors through \(\tau\).  This is independent of \(r\): a
coarse query view cannot be repaired by making more memory reads.  It says
nothing, however, about how the resulting factor depends on \(S\).
\end{remark}

\begin{remark}[A navigation-style representation limit]
The locality criterion can diagnose an external-memory navigation interface
without treating that memory as an instance of \(\SAF\).  Suppose a navigation
task must choose an action from a declared query view and the content reads
admitted by \(\pi\).  If two environments expose the same
\(\bigl(\tau(q),\operatorname{tr}_{\pi}(S,\tau(q))\bigr)\)--as can occur
when the representation exposes the same unordered visual-feature multiset
but not connectivity--yet their different connectivity requires different
actions, then (L) fails.  Theorem~\ref{thm:locality} therefore rules out an exact
deterministic no-bypass executor for that declared observation interface.
This is not an instance of Proposition~\ref{prop:openworld}: both
environments require an action rather than one requiring abstention.

The conclusion is only an interface-insufficiency statement, not a claim
that a navigation system is learnable or unlearnable.  In particular, whether
a real feature extractor produces such indistinguishable transcripts is an
empirical question.  A continuous or similarity-addressed environment memory
also need not have exact keys or decidable membership, so the \(\SAF\) and
one-shot Store theorems do not apply merely by calling it a memory.
\end{remark}

\begin{remark}[Oblivious plans and the real access budget]
The earlier ``fixed read set'' condition would measure the support of an
oblivious plan, not the number of physical reads.
The adaptive formulation is not merely cosmetic: a two-read policy may first
read a pointer \(p\) and then read the referent named by its value, whereas
an oblivious plan for the same task can require every possible target.
Corollary~\ref{cor:gap} gives an unbounded point-read separation under this
declared interface.  Here \(r\) always counts actual point reads along a
runtime path.
\end{remark}

\begin{proposition}[A nontrivial two-hop target]\label{prop:twohop}
There is a finite instance of the preceding model with a target
\(B:\mathcal S_{\Wr_0}\times\Qu_0\to\mathcal Y\) for which an exact
no-bypass executor exists with \(r=2\), but no exact no-bypass executor
exists with \(r=1\), for any adaptive one-read policy using the same query
view.
\end{proposition}

\begin{proof}
Let \(\mathcal R\) be a finite set with \(\lvert\mathcal R\rvert\geq2\),
let \(\Dom_0=\{p\}\sqcup\mathcal R\),
\(\Va=\mathcal R\sqcup\{0,1\}\), and
\(\mathcal Y=\{0,1,\bt\}\).  For every \(d\in\Dom_0\), take a query
\(q_d\), set \(\Qu_0=\{q_d:d\in\Dom_0\}\), let \(\semq(q_d)=d\), and
set \(\tau(q_d)=d\).  Let \(\Wr_0\) consist of \(w_{p,t}\) with
\(\semw(w_{p,t})=(p,t)\) for each
\(t\in\mathcal R\), and \(w_{t,b}\) with
\(\semw(w_{t,b})=(t,b)\) for each \(t\in\mathcal R\) and
\(b\in\{0,1\}\).  Define
\[
 B(S,q_d)=S^{\bt}(d)\quad(d\in\mathcal R),
 \qquad
 B(S,q_p)=
 \begin{cases}
   S^{\bt}(t), & S^{\bt}(p)=t\in\mathcal R,\\
   \bt, & \text{otherwise.}
 \end{cases}
\]

For \(r=2\), let \(\pi\) first read \(d\) on query view \(d\in\mathcal R\)
and halt thereafter.  On query view \(p\), it first reads \(p\), then reads
\(t\) exactly when the first value is \(t\in\mathcal R\), and otherwise
halts.  An executor returns the sole value for a direct query, the second
value after the trace \(((p,t),(t,x))\), and \(\bt\) after \(((p,\bt))\).
It is exact on \(\mathcal S_{\Wr_0}\), so condition (L) holds there by
Theorem~\ref{thm:locality}.

For the lower bound, consider \(q_p\).  Every one-read policy chooses a
fixed first action on the common initial input \((p,\varepsilon)\).  If it
halts, fix any \(t\in\mathcal R\); the two histories
\(H_b=(w_{p,t},w_{t,b})\), \(b=0,1\), give it the same empty transcript but
different answers.  Otherwise it chooses a
referent \(d\).  If \(d=p\), fix \(t\in\mathcal R\) and compare the legal histories
\(H_b=(w_{p,t},w_{t,b})\) for \(b=0,1\): they return the same read value
\(t\) but have different answers.  If \(d\in\mathcal R\), choose
\(t\in\mathcal R\setminus\{d\}\) and use the same two histories: the
first read is \(\bt\) in both while the answers differ.  Thus (L) fails for
every one-read policy, and Theorem~\ref{thm:locality} rules out an exact
one-read executor.

Finally, take a key space admitting an injective
\(\kappa:\Dom_0\hookrightarrow\Ky\), set \(C_w(w)=\kappa(d)\) whenever
\(\semw(w)=(d,v)\), and set \(C_r(q_d)=\kappa(d)\).  This gives \(\SAF\),
and \(\rho(d)=q_d\) is a fixed query-witness selector, so the two semantic
reads above also have the physical realization of
Corollary~\ref{cor:composition}.
\end{proof}

\begin{corollary}[Unbounded address-adaptivity point-read gap]
  \label{cor:gap}
For every integer \(m\geq2\), the instance of
Proposition~\ref{prop:twohop} with \(\lvert\mathcal R\rvert=m\) has an
exact adaptive two-read executor, while every exact no-bypass executor whose
policy is address-oblivious on \(\mathcal S_{\Wr_0}\) relative to the same
\(\tau\) has worst-case cost at least \(m+1\) semantic point reads on
query \(q_p\).  This bound is tight: an oblivious executor that reads every
referent in \(\Dom_0\) is exact and has cost \(m+1\) on \(q_p\).
\end{corollary}

\begin{proof}
Fix an address-oblivious policy and query \(q_p\), and let \(D\) be the
underlying set of its fixed nonrepeating referent sequence
\((d_1,\ldots,d_s)\).  We use the following prefix fact.  If two states
agree on \(d_1,\ldots,d_j\), then their executions have identical behavior
through the first \(j\) possible reads: they either halt at the same earlier
step with the same transcript, or they both make \(j\) reads with the same
transcript and, when \(j<s\), make the same decision whether to continue.
This follows by induction: equal prior \((u,h_t)\) inputs give the same halt
decision; if both continue, address-obliviousness gives the same next
referent \(d_{t+1}\), where the states agree.

First suppose \(p\notin D\).  Choose distinct \(t_0,t_1\in\mathcal R\) and compare
the legal histories
\[
 H_0=(w_{p,t_0},w_{t_0,0},w_{t_1,1}),
 \qquad
 H_1=(w_{p,t_1},w_{t_0,0},w_{t_1,1}).
\]
Every read in \(D\) has the same value in the two induced states, so the
prefix fact at \(j=s\) gives identical complete transcripts.  Since
\(B(S_{H_0},q_p)=0\neq1=B(S_{H_1},q_p)\), exactness requires \(p\in D\).

Likewise, every \(t\in\mathcal R\) must occur in \(D\): if it did not,
the histories \(H_b=(w_{p,t},w_{t,b})\), \(b=0,1\), would by the preceding
prefix fact induce the same complete transcript, yet have different answers.  Hence
\(D=\Dom_0\).  Let \(d_\star\) be the last referent in the fixed sequence.
If \(d_\star=t\in\mathcal R\), then on the two histories
\(H_b=(w_{p,t},w_{t,b})\), \(b=0,1\), an exact executor cannot halt before
reading \(t\): the prefix fact at \(j=m\) makes any earlier halt occur on
both histories with the same transcript, despite their different answers.
If \(d_\star=p\), use the two histories \(H_0,H_1\) above instead; the
prefix fact at \(j=m\) gives the same conclusion.  Thus the policy makes
all \(m+1\) reads in the worst case.
Theorem~\ref{thm:locality} rules out a smaller exact executor.  Conversely,
an oblivious policy that reads every referent in \(\Dom_0\) is exact with an
executor that, on \(q_p\), returns \(\bt\) if its read at \(p\) is \(\bt\)
and otherwise returns the observed value at the referent named by that read;
on \(q_d\), \(d\in\mathcal R\), it returns the observed value at \(d\).
The adaptive two-read upper bound is Proposition~\ref{prop:twohop}.
\end{proof}

\begin{remark}[Where the content is]
Theorem~\ref{thm:locality} is deliberately a realizability criterion, not a
claim that an arbitrary given executor is exact.  It is non-vacuous only when
\(r\), \(\tau\), and \(\pi\) are declared independently of the implementation
and \(r\) is a real access constraint.  Otherwise an implementation can
supply its whole current state to \(E\) and conceal all work there.  Thus it
formalizes a conditional interface claim, not an assertion that ``reasoning''
and ``knowledge'' are independently learnable or orthogonal.  With exact
addressing for every point read selected by \(\pi\),
Theorem~\ref{thm:factor} supplies the memory-side condition; the executor
side remains the separately specified function \(E\).
\end{remark}

\section{Semantic address factorization}

\begin{definition}[Semantic Address Factorization]\label{def:saf}
An interface \((C_w,C_r)\) has \emph{Semantic Address Factorization}
(\(\SAF\)) on \((\Wr_0,\Qu_0)\) when all four conditions hold:
\begin{enumerate}
  \item[(C1)] \emph{Typed determinacy:} the interface has one deterministic
  output in \(\Ky\cup\{\bt\}\) for each input; membership in \(\Ky\) is
  exactly decidable.
  \item[(C2)] \emph{Covered positive inputs:} for every \(w\in\Wr_0\) and
  \(q\in\Qu_0\), \(C_w(w),C_r(q)\in\Ky\), not \(\bt\).
  \item[(C3)] \emph{Write--read agreement:} if
  \(\semw(w)=(d,v)\) and \(\semq(q)=d\), then \(C_w(w)=C_r(q)\).
  \item[(C4)] \emph{Live-referent separation:} if two covered write or query
  inputs denote distinct referents, their outputs are distinct keys.
\end{enumerate}
\end{definition}

\begin{proposition}[SAF induces a naming map]\label{prop:naming}
Under the bi-witnessed-scope assumption, \(\SAF\) holds if and only if there
exists an injective map \(\kappa:\Dom_0\hookrightarrow\Ky\) such that
\[
 C_w(w)=\kappa(d)\quad\text{whenever }\semw(w)=(d,v),
 \qquad
 C_r(q)=\kappa(d)\quad\text{whenever }\semq(q)=d .
\]
\end{proposition}

\begin{proof}
For the forward direction, define \(\kappa(d)\) using any write witness for
\(d\).  (C3) makes the choice of write witness and every query witness agree,
and (C4) makes \(\kappa\) injective.  The reverse direction gives (C2)--(C4)
immediately, while (C1) is part of the interface model.
\end{proof}

\begin{theorem}[Universal-store address factorization]\label{thm:factor}
In the setting of Definitions~\ref{def:task}--\ref{def:execution}, an
interface has \(\UE\) if and only if it has \(\SAF\) on the covered scope.
\end{theorem}

\begin{proof}
Assume first \(\UE\).  A one-write history followed by a query witness for
the written referent shows that neither interface may output \(\bt\): the
write must be admitted and the query must return a value in \(\Va\).  The
same one-write history has exactly one live key.  Therefore a write witness
and query witness for the same \(d\) must yield the same key, or the query
would return \(\bt\) rather than its written value.  Finally choose distinct
referents \(d,d'\) and witnesses for each.  If the two addresses coincided,
the second legal write would conflict with the first at one physical key,
contradicting universal admission.  Hence (C1)--(C4)
hold.

Conversely, Proposition~\ref{prop:naming} gives an injective \(\kappa\).
Every legal history writes distinct referents to distinct keys
\(\kappa(d)\), so all writes are admitted and the resulting store contains
exactly \(S_H(d)\) at \(\kappa(d)\).  A covered query for \(d\) reads that key
when \(d\in\operatorname{dom}S_H\), and reads an absent key otherwise.  Its
output is therefore \(\Alkup(S_H,q)\).
\end{proof}

\begin{definition}[Anchored physical point reads]\label{def:anchor}
A \emph{fixed query-witness selector} is a map
\(\rho:\Dom_0\to\Qu_0\) satisfying
\(\semq(\rho(d))=d\) for every \(d\in\Dom_0\).  It is part of the
declared runtime interface, not selected after observing an execution.  Such
a selector exists under bi-witnessed scope and is automatically injective,
since \(\semq\circ\rho=\operatorname{id}_{\Dom_0}\).  It is \emph{faithful} for an
addressing interface if every legal history is admitted, and for every legal
history \(H\) and \(d\in\Dom_0\), \(C_r(\rho(d))\in\Ky\) and
\[
 \mathrm{get}\bigl(M_H,C_r(\rho(d))\bigr)=S_H^{\bt}(d). \tag{F}
\]
\end{definition}

\begin{lemma}[SAF supplies a faithful anchor]\label{lem:anchor}
If \(\SAF\) holds, every fixed query-witness selector is faithful.
\end{lemma}

\begin{proof}
By Proposition~\ref{prop:naming}, \(C_r(\rho(d))=\kappa(d)\).  The legal
history writes exactly the live semantic values at the pairwise distinct keys
\(\kappa(d)\).  Hence this exact read returns \(S_H(d)\) when defined and
\(\bt\) otherwise.
\end{proof}

\begin{theorem}[Physical realization of adaptive semantic reads]
  \label{thm:bridge}
Fix \(\tau\), an adaptive \(r\)-read policy \(\pi\), a fixed
query-witness selector \(\rho\), and a deterministic executor \(E\).
Suppose \(\rho\) is faithful and the semantic execution
\[
 E\bigl(\tau(q),\operatorname{tr}_{\pi}(S_H,\tau(q))\bigr)
\]
equals a target answer \(B(S_H,q)\), for some
\(B:\mathcal S_{\Wr_0}\times\Qu_0\to\mathcal Y\), on every legal history
\(H\) and query \(q\).  Then a physical executor can realize the same
computation with at most \(r\) exact Store reads: whenever \(\pi\) chooses
semantic referent \(d\), it reads the physical key \(C_r(\rho(d))\), passes
the resulting value to \(\pi\), and finally applies \(E\).  In particular,
by Lemma~\ref{lem:anchor}, \(\SAF\) is a convenient sufficient condition for
faithfulness and hence for this realization.
\end{theorem}

\begin{proof}
Induct on the read step.  Faithfulness (F) makes the physical value at every
chosen \(d\) equal to \(S_H^{\bt}(d)\).  Thus the physical and semantic
transcripts are equal at each step, so the deterministic policy makes the
same next choice and eventually the two executors present the same input to
\(E\).  The assumed semantic correctness gives the result.
\end{proof}

\begin{corollary}[Anchored composition]\label{cor:composition}
Fix \(\tau\), \(\pi\), and \(\rho\) as above.  If \(\SAF\) holds and a
target \(B:\mathcal S_{\Wr_0}\times\Qu_0\to\mathcal Y\) satisfies condition
(L), with \(A\) replaced by \(B\) and state scope
\(\mathcal X=\mathcal S_{\Wr_0}\), then there exists a physical executor
using at most \(r\) exact Store reads that returns \(B(S_H,q)\) for every
legal history \(H\) and query \(q\).
\end{corollary}

\begin{proof}
Apply Theorem~\ref{thm:locality} with
\(\mathcal X=\mathcal S_{\Wr_0}\) to obtain an exact semantic executor.
By Lemma~\ref{lem:anchor}, \(\SAF\) makes \(\rho\) faithful; then apply
Theorem~\ref{thm:bridge}.
\end{proof}

\begin{remark}[The bridge is sufficient, not necessary]
Theorem~\ref{thm:bridge} fixes the public physical operation for semantic
referent \(d\) to be the declared key \(C_r(\rho(d))\).  Its operative
interface premise is faithfulness (F); \(\SAF\) is only a convenient
sufficient source of (F), not a necessary condition for anchored
realization.  This strictness needs no private key knowledge: with one
referent \(d\), two query witnesses \(q_1,q_2\), and
\(C_w(w)=C_r(q_1)=k\) but \(C_r(q_2)=k'\neq k\), (C3) and hence \(\SAF\)
fail, whereas \(\rho(d)=q_1\) is faithful.  An executor explicitly given an
inverse of a private fixed key relabeling is a separate way to leave the
anchored interface altogether.
\end{remark}

\begin{remark}[Pointer values]
No separate map \(\nu:\Va\rightharpoonup\Dom_0\) is needed to realize a
\emph{given} policy \(\pi\): if a value is to determine a next referent, the
value-to-referent decision is already part of \(\pi(u,h)\).  A separate
\(\nu\) is needed only for a more structured claim that the policy factors
through a designated pointer interpretation; \(\SAF\) neither provides nor
learns that interpretation.  Moving a pointer representation from a read
value to a stored key relocates this semantic obligation rather than removing
it.  The budget \(r\) bounds Store reads only; it does not bound \(\pi\)'s
internal computation, including any work that interprets a retrieved value
as a next referent.
\end{remark}

\begin{remark}[Responsibility boundary]\label{rem:boundary}
The necessity proof supplies the precise limit of an exact membership guard.
If an upstream query interface emits the live address \(\kappa(d')\) for
\(d'\neq d\), then in any legal state in which both referents have unequal
values, exact \(\mathrm{get}\) returns a genuinely present but wrong value.
Membership can certify that an address exists; it cannot certify that it is
the intended referent or repair an identity error upstream.
\end{remark}

\section{Certified abstention is an additional assumption}

SAF concerns a fixed covered scope.  It does not make the phrase ``genuinely
unknown'' mathematical.  To make a fail-closed claim outside that scope, a
task must provide certificate relations
\(\mathsf{Cert}_w\subseteq\Wr\times\Ky\) and
\(\mathsf{Cert}_r\subseteq\Qu\times\Ky\), together with a soundness
assumption relative to the semantic maps and the \(\kappa\) of
Proposition~\ref{prop:naming}.  A certified partial interface may emit a key
only with a valid certificate and emits \(\bt\) when no certificate exists.
In a finite closed world this can be supplied by enumeration.  It is not
supplied automatically by an embedding, a confidence score, or this theorem.

\begin{definition}[Observational ambiguity]\label{def:ambiguity}
Let \(x\) contain every input visible to an abstention policy.  An open-world
specification is \emph{observationally ambiguous} at \(x\) if it admits two
legal worlds with the same \(x\), one requiring answer \(\bt\) and one
requiring a live key \(k\in\Ky\).
\end{definition}

\begin{proposition}[No free open-world abstention]\label{prop:openworld}
No deterministic policy of the visible observation \(x\) can be both exact
in every world of an observationally ambiguous specification and complete on
its live-key world.
\end{proposition}

\begin{proof}
The policy has the same output on the identical observation \(x\).  If it
outputs \(\bt\), it is incomplete in the live-key world; if it outputs a key,
it is wrong in the absent world.
\end{proof}

\begin{remark}
Proposition~\ref{prop:openworld} is an indistinguishability statement, not a
claim that open-world language understanding is impossible.  Without an
observation model and a certificate/coverage assumption, ``open-world
impossibility'' is not yet a well-posed theorem.  In particular, if the
visible observation contains an exact \(S^{\bt}(d)\) readout that distinguishes
the two worlds, Definition~\ref{def:ambiguity} does not apply; this is why
the proposition does not conflict with
Theorem~\ref{thm:locality}.
\end{remark}

\section{Imported results and non-results}\label{sec:imports}

This section records adjacent results with their assumptions.  None proves
Theorem~\ref{thm:factor}; conversely, Theorem~\ref{thm:factor} makes no claim
about the expressivity or trainability addressed by these works.

\begin{imported}[Log-precision transformer upper bound]
Merrill and Sabharwal~\citep{merrill2022parallelism} show that a Transformer
operating on \(\Sigma^n\) with fixed depth \(d\), \(c\log n\)-bit precision
at every intermediate operation, and the paper's bounded-precision component
functions is simulated by a logspace-uniform threshold-circuit family of
depth \(3+(9+2d_{\oplus})d\).  Their Definition~6 entails that the component
functions are computable in \(O(\log n)\) space; hence this stated model lies
in uniform \(\mathsf{TC}^0\).  This is not an upper bound for arbitrary
real-precision or recurrent/looped implementations.
\end{imported}

\begin{imported}[Saturated-attention upper bound]
Merrill, Sabharwal, and Smith~\citep{merrill2021saturated} define
\(\mathsf{AHAT}(F)\) as finite-depth, finite-head Transformers over their
floating-point datatype \(F\), with saturated attention and
size-preserving embedding, score, and feed-forward functions.  Their
Theorem~5 is \(\mathsf{AHAT}(F)\subseteq\mathsf{TC}^0\) (non-uniform).
The result is model-specific: their rational-valued, size-preserving variant
can recognize every formal language under different assumptions.
\end{imported}

\begin{imported}[Arbitrary-precision Turing completeness]
P\'erez, Marinkovi\'c, and Barcel\'o~\citep{perez2021turing} prove Turing
completeness for hard-attention Transformer networks with positional
encodings, rational weights and activations of arbitrary precision, and their
piecewise-linear sigmoidal activation.  It is therefore not evidence that a
finite-precision, fixed-depth deployed language model has unbounded practical
memory.
\end{imported}

\begin{imported}[Serial computation from chain of thought]
Li, Liu, Zhou, and Ma~\citep{li2024cot} show that with \(T\) generated
chain-of-thought steps, constant-depth Transformers of constant-bit precision
and \(O(\log n)\) embedding size can solve every problem computable by Boolean
circuits of size \(T\), under their decoder-only formal model.  This concerns
serial expressivity, not semantic address agreement.
\end{imported}

\begin{imported}[External-memory architectures and empirical retrieval]
Neural Turing Machines introduce differentiable attentional reads and writes
to external memory~\citep{graves2014ntm}; Differentiable Neural Computers
extend that architectural line~\citep{graves2016dnc}.  In language modelling,
kNN-LM~\citep{khandelwal2020knnlm}, RAG~\citep{lewis2020rag}, and Memorizing
Transformers~\citep{wu2022memorizing} report empirical gains from external or
non-parametric memory.  These are architectural or empirical results; none
proves universal semantic identity preservation, \(\SAF\), or zero
misdelivery over all stores.
\end{imported}

\begin{imported}[Risk guarantees for RAG]
C-RAG~\citep{kang2024crag} gives conformal generation-risk guarantees for
retrieval-augmented language models under its bounded-risk and retrieval/model
quality assumptions.  A generation-risk certificate is not a proof that a
retrieved key denotes the intended referent, so it does not subsume the
identity condition in Theorem~\ref{thm:factor}.  The two guarantees are
logically distinct: unless the evaluation loss and coverage assumptions
separately make referent identity observable, a risk guarantee does not imply
identity soundness.
\end{imported}

\begin{remark}[Two prohibited shortcuts]
Barrington's theorem characterizes nonuniform \(\mathsf{NC}^1\) by bounded
width polynomial-size branching programs~\citep{barrington1989}.  It does
not license an unconditional Transformer lower bound when juxtaposed with a
\(\mathsf{TC}^0\) upper bound: the requisite complexity-class separation is
not known.  Likewise, ``\(b\) bits per parameter'' only counts finite
parameter encodings; without a task encoding and precision assumptions, it
is not a lower bound on factual capacity.
\end{remark}

\section{Conjecture and limits}

\begin{conjecture}[Scale and addressability]\label{conj:scale}
Whether unsupervised training at scale produces SAF-like write--read agreement
on nontrivial natural-language scopes is open.  This note makes no claim in
either direction.
\end{conjecture}

The note does not claim that natural-language canonicalization is achievable
or impossible, that latent delivery is superior to textual context, that a
value codec or reasoning executor can be learned, or that a measured failure
of a particular neural mechanism refutes SAF.  Nor does its declared
point-read, worst-case separation imply an advantage for neural architectures
or learned address decoding.  Within fixed schemas, zero-error point reads,
no-bypass execution, and the declared state/query/policy scopes, it instead
characterizes a one-shot exact address interface, an executor-locality and
physical-realization boundary for bounded reads, a family of finite tasks
with an unbounded address-adaptivity gap, and the extra observational
assumptions required for open-world abstention.
